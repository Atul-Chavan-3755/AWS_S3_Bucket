## What is S3 ?
Amazon S3 (Simple Storage Service) is a cloud storage service.  
It allows you to store and retrieve any amount of data from anywhere on the web.

## What can you store in these S3 ?  
S3 service allows you to create buckets in which you can store anything, and You can store huge size of data.  
Ex. Files, JPG, CSV, Videos, and any other kind of data.  

## Benefits or Advantages of S3
- Scalable
- High availability
- Secure
- Cost effective
