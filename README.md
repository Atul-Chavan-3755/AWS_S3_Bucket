## What is S3 ?
Amazon S3 (Simple Storage Service) is a cloud storage service.  
It allows you to store and retrieve any amount of data from anywhere on the web.
- Scalable
- High availability
- Secure
- Cost effective

## What can you store in these S3 ?  
S3 service allows you to create buckets in which you can store anything.  
Ex. Files, JPG, CSV, Videos, and other any kind of data.
