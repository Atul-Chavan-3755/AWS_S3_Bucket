## What is S3 ?
Amazon S3 (Simple Storage Service) is a cloud storage service.  
It allows you to store and retrieve any amount of data from anywhere on the web.

## What can you store in these S3 ?  
S3 service allows you to create buckets in which you can store anything, and You can store huge size of data.  
Ex. Files, JPG, CSV, Videos, and any other kind of data.  

## Benefits or Advantages of S3
- Scalable
- High availability
- Secure
- Cost effective

## Key Features Used  
1. Bucket Creation  
Globally unique bucket name  
Region-specific deployment (e.g., ap-south-1)  
2. Versioning  
Enabled to keep multiple versions of objects  
Helps in rollback and recovery  
3. Access Control  
IAM-based access using roles and policies   
Bucket policies to control public/private access  
4. Static Website Hosting  
Configured to host frontend applications  
Uses index.html as entry point  
5. Lifecycle Policies  
Automatically moves old data to cheaper storage (Glacier)  
Deletes unused objects after defined time  
6. Encryption  
Server-side encryption enabled (SSE-S3 or SSE-KMS)
